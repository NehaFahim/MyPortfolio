# 👩‍💻 Neha Fahim – Personal Portfolio Website

Welcome to my personal portfolio – a modern and fully responsive web application built using **Next.js** and **Tailwind CSS**. This website serves as a central hub to showcase my **frontend development projects**, **technical skills**, and **professional experience**. Whether you're a recruiter, client, or fellow developer, this portfolio is designed to give you insight into my abilities and approach to web development.

---

## 🔍 Overview

As a dedicated **Frontend Developer** with a strong foundation in  **Next.js**, **Tailwind CSS**, and **TypeScript**, I have created this portfolio to reflect both my technical proficiency and design sensibilities. The site includes:

- An **About** section detailing my background and journey.
- A **Projects** section that highlights real-world applications I have built.
- A **Resume** section for quick access to my qualifications.
- A **Contact** form that allows visitors to reach out directly.
- A clean, minimal, and responsive layout that works across all devices.
